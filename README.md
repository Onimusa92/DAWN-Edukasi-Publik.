# DAWN Edukasi Publik
Selamat datang di repositori untuk mempelajari tentang DAWN, jaringan broadband nirkabel desentralisasi!

## Apa Itu DAWN?
DAWN adalah inisiatif yang dikembangkan oleh tim @andrena_wifi untuk menyediakan akses internet cepat dan terjangkau melalui teknologi desentralisasi. Antena rooftop-nya dapat mencapai jangkauan 5 mil dan mendukung 15-100 node.

## Manfaat
- Internet cepat untuk wilayah terpencil.
- Memberdayakan komunitas untuk berbagi bandwidth.
- Teknologi ramah lingkungan dan terjangkau.

## Cara Belajar
1. Baca dokumen di folder Dokumentasi.
2. Ikuti tutorial di folder Panduan.
3. Diskusikan di GitHub Discussions.
